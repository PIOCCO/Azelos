# Client onboarding

```text
Scoping workshop → Select TSC → config/clients/<id>.yaml
→ Validate → Gap assessment → Implement controls / policies
→ Terraform (optional) → Evidence collection → Continuous monitoring
→ Auditor engagement (external)
```

Checklist:

- [ ] Criteria selected and scope documented
- [ ] Policies customized and approved
- [ ] Automated + manual controls assigned owners
- [ ] Evidence retention configured
- [ ] Integration paths to BCDR / hosting inventory (if used)
- [ ] Readiness report reviewed — gaps remediated before audit fieldwork
