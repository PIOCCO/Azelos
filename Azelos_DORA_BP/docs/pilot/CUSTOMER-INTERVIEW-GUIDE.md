# Customer interview guide

Use at **mid-pilot** and **end of pilot**. Neutral wording; prefer open follow-ups (“Tell me more about that”).

## Core questions

1. What problem were you trying to solve with this pilot?
2. How did you handle this work **before** the Blueprint?
3. Which part of the **workflow was useful**?
4. Which part was **confusing** or slow?
5. What work did you **continue doing manually** (Excel, email, other tools)?
6. What **information or fields** were missing?
7. What **prevented wider usage** within the team?
8. Who would need to use this in **production** (roles)?
9. How **frequently** would they use it (daily / weekly / monthly / ad hoc)?
10. What **other systems** would it need to connect to?
11. What would **prevent production adoption** if unchanged?
12. What would make the system **operationally valuable** on an ongoing basis?

## Optional (non-leading) follow-ups

- “Can you walk me through the last time you used the relationship map?”
- “What happened when you tried to produce a report for a meeting?”

## Avoid

- “Would you agree this saves a lot of time?”
- “Don’t you think DORA compliance is easier now?”
- “Would you definitely buy this?”

Record answers verbatim where possible; attribute to role, not name, in shared notes if privacy required.
