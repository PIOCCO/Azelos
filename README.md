# Azelos

Client project: **دار المغرب (MaisonMaroc)** — bilingual Moroccan real-estate marketplace.

## Run the marketplace

```bash
cd maisonmaroc
npm install
npm run dev
```

Open the URL from the terminal (default `http://localhost:5173`). Arabic RTL is the default; switch with **العربية | Français**.

See [maisonmaroc/README.md](maisonmaroc/README.md) for features, pages, and data model.
